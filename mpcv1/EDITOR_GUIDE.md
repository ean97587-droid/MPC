# MPC Editor Guide

## Add or replace a team headshot
Open **Team**, expand the person's entry, choose **Headshot**, upload/select the image, then save.

## Add a new team member
Open **Team**, choose Executive Team / Senior Analysts / Junior Analysts, add an item, enter the person's details, upload a headshot, then save. Drag/reorder items to control display order where the editor permits.

## Add an upcoming event
Open **Events → Upcoming events**, add an item, enter the title, speaker, firm, date/time and description, upload the speaker headshot, then save.

## Turn an upcoming event into a past event
Copy/create it under **Past events**, add event photos if desired, then remove it from **Upcoming events** and save.

## Add past-event photos
Open **Events → Past events**, expand the event, then use **Event photo gallery**. Upload up to 20 images. The live site shows them as clickable gallery thumbnails with an expanded lightbox view.

## Change applications
Open **Site & Applications → Site settings**. Change:
- Application status
- Application deadline / note
- Application form URL
Then save.

## Add a placement firm
Open **Placements**, add the firm to the appropriate list, upload a logo (preferred) or use an external logo URL, choose the closest sizing option, then save.
